# 下一轮输入建议

独立的 DSH 插件 `@local/dsh-next-input`，适配已核验的 **DSH 0.2.2-rc.3**。

## 使用

会话一轮正常结束且输入框为空时，插件自动检查最近的用户输入和助手回答。明确的“未确认事项、证据尚未取得、仍不能下结论”等结果会优先生成安全的本地下一步准备建议；其他情况由模型判断是否仍有任务缺口，并在输入框上方显示一条 **下一轮建议**。待办已完成不等于证据或结论已经闭合。

- 点击建议：只填入空白草稿，随后可编辑，**不会发送**。
- 点击关闭：忽略本轮建议。
- 已有文字（含空格）、附件、发送中、运行中的会话、子智能体会话均不显示建议；不会覆盖草稿。
- 没有明确缺口：不显示建议，原输入框和背景文案保持原样。
- 模型返回无效结果、调用失败或超时：仅显示可关闭的“本轮建议暂不可用”提示，不改草稿，不把失败伪装成“没有缺口”。
- 新一轮开始后旧建议失效；切换会话不会把旧结果填到新会话。

**为什么不是直接替换背景文案？** 当前版本没有公开的占位文案扩展接口。本插件使用原生的附加槽位 `conversation.input.dock`，不替换输入框、不改 DSH 安装目录、不读写其他插件的 DOM，不接管 Enter/Tab 等快捷键。

## 数据与费用

明确的未确认章节优先使用本地规则生成证据清单/验证计划类建议，不发起额外模型请求；权限受阻时只建议准备所需证据与权限申请，不代表授权或继续访问。其他情况使用刚结束一轮的模型路由，对限量的最近对话文本发起额外的辅助请求，可能产生模型服务费用。不会运行工具、发送用户消息、唤醒目标或创建新会话。默认采用该模型支持的较低思考强度；不保证一定无思考开销。

本地规则和模型判断都不是确定性的任务验收：有限历史、文本截断以及未读取图片或附件，均可能导致遗漏或误判。不会把工具结果或系统指令发送给辅助模型。建议缓存仅驻留内存，重启后可能对当前已完成轮重新判断；没有完整的请求重放/审计记录。

关闭插件即停止新增建议，已经点击填入的草稿继续由 DSH 原输入框保存。

## 安装

在 DSH **插件 → 添加插件** 中选择本目录。也可以要求智能体用原生 `plugin_manager` 安装该目录。安装影响当前 profile 的所有会话；以安装器返回的应用状态为准，若提示重启则重启。

包内包含构建完成的客户端文件，安装无需运行生命周期构建脚本。源码链接安装后修改代码，不等于浏览器已收到更新；根据 DSH 的重新加载/重启提示操作。

## 开发与测试

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm build
pnpm test
```

Node.js 24+，pnpm 11.28.5。客户端使用 DSH 自带的 React 实例，不另外打包 React。开发构建依赖 esbuild；运行依赖 zod、schemastery。此插件尚未发布，没有已发布安装包或线上索引入口。

测试覆盖纯投影、上下文截断、保守解析、单轮去重、调用结束状态、取消/过期结果、并发上限、空草稿与附件/编辑竞争保护。在 DSH 内运行时，还使用本机安装的 Cordis/Typert/Gateway 进行隔离集成测试，验证作用域身份绑定、真实 `RemoteResult` 封包解析、有建议/无缺口的展示选择及失败分支；该测试不打开浏览器、不读个人会话、不调用付费模型。离开 DSH 环境时该安装契约测试会显式跳过。

不把槽位注册成功或隔离集成测试等同于真实页面验收；没有浏览器控制时，仍需人工检查明暗主题、真实模型判断及点击流程。

## 1.0.3 未确认事项与诊断

- 明确的“仍不能下定论 / 未确认项 / 待验证”章节只要包含具体未解决事实，就优先显示本地准备建议；不会因待办已完成、原验收未写明进一步验证或辅助模型返回空而消失。
- 审批/权限受阻时只生成证据清单和权限申请准备输入，不继续查询，不视为用户授权；用户明确要求停止、仅总结、不跟进时仍保持安静。
- 长会话压缩移除首条任务摘录后，最新完整回答中的明确未确认项仍可触发安全的计划类提示；旧的被替换文本仍会失效。投影版本为 3。
- 在提供 Inspect 的环境下，Host/Client 都可只读查询 `NextInput.status`，核对**实际加载代码**的版本、触发状态、草稿/附件是否阻挡、缓存结果或失败原因；不返回对话正文、草稿、标题或凭据，不触发模型。查询作用域是发起 Inspect 的会话，不一定是页面当前选择的会话。

## 1.0.2 交互样式

- 建议卡片与失败提示统一沿用原输入框的宽度轴与两侧留白，随内容宽度调整和窄屏变化，不再横跨整页。
- 失败提示改为低干扰的信息卡片，信息图标、提示文字与关闭按钮集中在同一行，长文案可换行。
- 统一间距、圆角、悬停/键盘焦点反馈；触屏关闭区域为 40×40，并支持减少动态效果偏好。关闭提示仍仅回到当前会话输入框，不改草稿。
- 此版本只调整客户端展示，不更改生成策略和模型调用参数。

## 1.0.1 修复

- 修复前端误把 `{ok, value}` 远程结果封包当成建议正文，导致成功响应也不显示的问题。
- 修复借用会话上下文直接读取 `remote` 的依赖权限问题，改为通过公开 `get()` 获取带会话身份的命名空间。
- 正常的系统提示单节点替换不再误清用户任务；真正触及已保留文本的替换仍会让旧建议失效。投影版本升至 2，以丢弃旧折叠缓存并重建。
- 请求失败与“判断无缺口”分开处理；前者显示可关闭提示，后者保持安静。升级已加载的插件后，以安装器的激活结果为准；若要求重启，必须重启 DSH，单纯刷新页面不能替换旧 Host 模块。
